MY QUEEN — ROMANTIC WEBSITE 💙

HOW TO OPEN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code.
3. Choose File > Open Folder, then select the extracted "my_queen_romantic_website" folder.
4. Open index.html.
5. For easiest preview, install the "Live Server" extension in VS Code, right-click index.html, and choose "Open with Live Server". You can also open index.html directly in a browser.

HOW TO SEND IT TO YOUR GIRLFRIEND ON WHATSAPP
A ZIP file sent on WhatsApp is a project folder, not a live website link. To let her open it like a website:
1. Upload index.html (the project is self-contained) to Netlify Drop at https://app.netlify.com/drop
   - You may need to sign in to Netlify to publish.
   - If the upload page requires a folder, upload the extracted project folder, or zip it again with index.html at the ZIP's top level.
2. Copy the public website URL Netlify gives you.
3. Send that URL to her on WhatsApp. She does not need a Netlify account to visit a published public site.
4. Keep the URL private if you only want to share it with her and a few friends, but remember that a public URL can still be opened by anyone who obtains it.

PERSONALIZE IT
Open index.html and edit the love-letter paragraphs and the "Your King" signature to make it sound like you. The site works on phones and computers and needs an internet connection only to publish/share the live URL.
